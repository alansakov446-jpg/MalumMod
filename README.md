# Ириска — бот-помощник по Iris | Чат-менеджер

Отвечает на вопросы про команды бота Iris (`@iris_cm_bot`) с помощью
бесплатного ИИ Groq (модели Llama). Работает бесплатно на GitHub Actions —
без сторонних хостингов.

## Как это работает

- **В группах/чатах**: нужно обращение — `!ириска <вопрос>`, `ириска, <вопрос>`
  или `.ириска <вопрос>` (регистр не важен). Например:
  `!ириска помоги замутить человека на 7 дней`
- **В личных сообщениях боту**: обращение не нужно, отвечает на любой текст.
- Ириска знает синтаксис команд Iris (файл `knowledge_base.md`) и подсказывает
  готовую команду.
- GitHub Actions по расписанию запускает `bot.py`, который держит соединение
  с Telegram (long polling) около 5 ч 50 мин, сам завершается — и через
  cron запускается заново. Так бот работает почти непрерывно бесплатно,
  без необходимости арендовать сервер.

## Шаг 1. Токен Telegram-бота

1. Напишите @BotFather в Telegram → `/newbot` → задайте имя и юзернейм.
2. Скопируйте выданный токен — это `BOT_TOKEN`.

## Шаг 2. Бесплатный API-ключ ИИ (Groq)

1. Откройте https://console.groq.com/keys (нужен обычный аккаунт, карта не
   требуется).
2. Нажмите **Create API Key**, скопируйте ключ (начинается с `gsk_...`).
   Это `GROQ_API_KEY`.
3. Groq регулярно меняет линейку бесплатных моделей и без предупреждения
   отключает старые (например, `llama-3.3-70b-versatile` и
   `llama-4-scout-17b-16e-instruct` в какой-то момент перестали быть
   доступны и стали отвечать ошибкой 404 «model_not_found»). Актуальный
   список моделей и лимитов всегда смотрите на
   https://console.groq.com/docs/rate-limits.
   В коде по умолчанию используется `groq/compound-mini` — это не отдельная
   модель, а «составная» система от Groq (сама выбирает базовую LLM и по
   желанию умеет дёргать инструменты вроде веб-поиска), но вызывается через
   тот же chat-completions API. На бесплатном тарифе у неё лимит **70 000
   токенов в минуту** — это важно, потому что вся `knowledge_base.md`
   (десятки команд Iris) целиком отправляется в системный промпт при
   каждом запросе и сама по себе занимает больше 10 000 токенов. У большинства
   обычных чат-моделей на бесплатном тарифе лимит всего **8 000 токенов в
   минуту**, из-за чего с такой большой базой знаний они будут упираться в
   ошибку 429 почти на каждом запросе. В коде уже отключены встроенные
   инструменты `compound-mini` (веб-поиск и т.д.), чтобы бот отвечал только
   на основе базы знаний, а не гуглил. Если Groq снова изменит доступные
   модели/лимиты — сначала проверьте `console.groq.com/docs/rate-limits` и
   ищите текстовую модель с TPM от ~15 000 и выше, либо сокращайте
   `knowledge_base.md`, либо смените модель через переменную `GROQ_MODEL`.

## Шаг 3. Разместить код на GitHub

1. Создайте **публичный** репозиторий (у публичных репозиториев минуты
   GitHub Actions бесплатны без ограничения; у приватных — лимит ~2000
   мин/месяц на бесплатном плане).
2. Залейте туда все файлы этого проекта, сохранив путь
   `.github/workflows/bot.yml`.

## Шаг 4. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository
secret**. Добавьте:

- `BOT_TOKEN` — токен из шага 1
- `GROQ_API_KEY` — ключ из шага 2

## Шаг 5. Запуск

Перейдите во вкладку **Actions → Ириска бот → Run workflow**, чтобы
запустить вручную и проверить, что всё работает. Дальше бот будет сам
перезапускаться по расписанию (каждые 6 часов).

Добавьте бота в свой чат (права можно дать минимальные — только читать
сообщения, ему не нужны права модератора Iris, он лишь советует команды).

## Важно понимать про такой способ хостинга

- Это не «настоящий» 24/7-сервер: между перезапусками возможен разрыв
  соединения на несколько минут (обычно короче), пока GitHub не подхватит
  следующий запуск по расписанию. Для бесплатного варианта — приемлемый
  компромисс.
- Не публикуйте токены в коде — только через Secrets.
- Если нужен настоящий 24/7 без пауз, дальше можно перенести тот же `bot.py`
  на бесплатный always-on воркер (например, отдельный VPS/Oracle Free Tier
  и т.п.) — код менять не придётся.

## Что ещё можно добавить Ириске

- **RAG по полному справочнику Iris**: вместо одного `knowledge_base.md`
  разбить официальный список команд на разделы и подтягивать только
  релевантный кусок под вопрос — так ответы будут точнее по редким командам
  (кланы, розыгрыши, биржа и т.д.).
- **Инлайн-режим** (`@bot вопрос` в любом чате) — Iris сам так умеет, можно
  повторить через `inline_query` в aiogram.
- **Готовые шаблоны одним нажатием**: кнопки «замутить», «забанить»,
  «выдать варн» с инлайн-клавиатурой, которая сама спрашивает срок/причину
  и собирает готовую команду Iris.
- **Логирование вопросов** в отдельный чат модераторов, чтобы видеть, чего
  людям не хватает в документации.
- **Ответы с учётом ранга** — если бот будет знать, кто модератор, а кто
  обычный участник, можно не предлагать команды, которые всё равно
  недоступны спрашивающему.
- **Кэш похожих вопросов**, чтобы экономить дневной лимит запросов к Groq.
- **Fallback на второй бесплатный ИИ** (например, Google Gemini) на
  случай, если дневной лимит Groq исчерпан.
